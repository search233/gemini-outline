# Gemini Outline (双子座大纲与提问导航助手)

一款专为 Google Gemini 网页端（`gemini.google.com`）打造的 Chrome 浏览器扩展（Manifest V3）。采用类似现代化技术博客与 [Section-Nav-for-ChatGPT](https://github.com/scandishoper/Section-Nav-for-ChatGPT) 的极简嵌入式设计，将 **ChatGPT 风格的右侧提问跳转栈 (Prompt Navigator)** 与 **纯文档章节大纲 (Section Rail)** 浑然一体地嵌入在 Gemini 对话区右侧的留白槽位中。

---

## ✨ 核心特性

- 🌿 **纯粹嵌入，无感相融**：
  - 彻底抛弃弹窗式侧边栏、抽屉大卡片与沉重边框；
  - 自动挂载在 Gemini 居中对话流右侧天然的空白槽位，宛如官方原生功能一般优雅自然。
- 💬 **ChatGPT 风格提问跳转栈 (Prompt Navigator)**：
  - 顶部以一组轻灵的水平小横条（`─ Q1`, `─ Q2`, `━ Q3`）展示各轮提问；
  - **悬停预览**：鼠标悬停在任一小横条上，自动弹出半透明微型气泡展示提问内容摘要；
  - **点击直达**：点击横条立即平滑滚动定位到该轮提问。
- 📑 **单回答纯文档章节大纲 (Section Rail)**：
  - 下方仅提取**当前处于阅读视口中的那一条 Gemini 回答**内部的 Markdown 标题（H1~H4）；
  - 极简博客风格：左侧细贯穿导轨线（Track Line）与层级缩进；
  - **ScrollSpy 滚动感知**：正文读到哪一个小节，导轨上的指示滑块与标题自动同步高亮；
  - **点击跳转**：点击标题平滑直达段落，并自动扣除顶部导航栏高度（防遮挡）。
- 🔄 **全自动双向联动**：
  - 在页面中上下滑动翻阅不同问答时，提问横条自动切换，大纲区平滑刷新为新回答的章节树；
  - Gemini 实时吐字打字时，提问栈自动新增并聚焦最新回答，大纲随字句实时长出。
- 🌓 **深浅色模式自适应**：
  - 自动检测并继承系统与 Gemini 原生深色/浅色配色方案。

## 🚀 安装与使用教程

### 步骤 1：在 Chrome / Edge 中加载插件
1. 打开 Chrome 浏览器，在地址栏输入：
   ```text
   chrome://extensions/
   ```
   *(如果使用 Edge 浏览器，请输入 `edge://extensions/`)*
2. 在页面右上角打开 **“开发者模式” (Developer mode)** 开关；
3. 点击左上角出现的 **“加载已解压的扩展程序” (Load unpacked)** 按钮；
4. 在弹出的文件选择器中，选择本项目的文件夹目录：
   ```text
   /home/yangz/Projects/gemini-outline
   ```
5. 看到扩展列表中出现 **Gemini Outline** 图标即表示安装成功！

### 步骤 2：在 Gemini 中体验
1. 打开或刷新 Google Gemini 网页端：
   [https://gemini.google.com](https://gemini.google.com)
2. 打开任意一段长对话：
   - 页面右侧将自动出现极其轻灵的 **提问小横条** 与 **当前回答大纲**；
   - 鼠标悬停在 `Q1`, `Q2` 查看提问，点击即可一键起飞跳转；
   - 滑动阅读回答，右侧标题高亮实时跟随，点击直接跳到对应小节。

## 🛠️ 技术实现细节

1. **视口阅读带评分器 (Active Answer Scorer)**：
   在视口顶部 10%~55% 设立黄金阅读感应带，动态计算各个回答在其中的重合权重，并加入防抖与迟滞阈值，解决滑动跨轮次时的闪烁问题。
2. **两级精准滚动定位**：
   通过自动查找 Gemini 的实际滚动容器（`infinite-scroller` / `.chat-history` / `window`），点击跳转时自动扣除顶部导航条 76px 的安全高度，并触发目标高亮波纹动效（Pulse）。
3. **流式打字与 SPA 路由观察**：
   借助 `MutationObserver` 与防抖合并（200ms），在 Gemini 流式吐字打字时实时追加标题，不卡顿、无冗余开销。
